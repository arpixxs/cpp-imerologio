# Conditions & Branching — `if` Statements in C++

## 1. What is Branching?

Branching lets a program **choose different paths** of execution based on a condition, instead of running every line top-to-bottom every time. This is done using **conditional statements** — the most fundamental being `if`.

```cpp
if (condition) {
    // runs only if condition is true
}
```

A "condition" is any expression that evaluates to `true` or `false` (a `bool`, or something implicitly convertible to `bool`).

---

## 2. Basic `if` Statement

```cpp
#include <iostream>

int main() {
    int age = 20;

    if (age >= 18) {
        std::cout << "You are an adult.";
    }
}
```

- If `age >= 18` evaluates to `true`, the block runs.
- If `false`, the block is skipped entirely — program continues after it.

---

## 3. `if...else`

```cpp
int age = 15;

if (age >= 18) {
    std::cout << "Adult";
} else {
    std::cout << "Minor";
}
```

Exactly **one** of the two blocks runs — never both, never neither.

---

## 4. `if...else if...else` (Multiple Branches)

```cpp
int marks = 75;

if (marks >= 90) {
    std::cout << "Grade: A";
} else if (marks >= 75) {
    std::cout << "Grade: B";
} else if (marks >= 50) {
    std::cout << "Grade: C";
} else {
    std::cout << "Grade: F";
}
```

**How it evaluates:** top to bottom, checks each condition in order, and stops at the **first** one that's `true`. The rest are skipped, even if they'd also be true.

```
marks = 75
→ 75 >= 90? No
→ 75 >= 75? Yes → prints "Grade: B", stops here
```

---

## 5. Comparison Operators (Building Conditions)

| Operator | Meaning | Example |
|---|---|---|
| `==` | equal to | `x == 5` |
| `!=` | not equal to | `x != 5` |
| `>` | greater than | `x > 5` |
| `<` | less than | `x < 5` |
| `>=` | greater than or equal to | `x >= 5` |
| `<=` | less than or equal to | `x <= 5` |

⚠️ **Common bug:** using `=` (assignment) instead of `==` (comparison):
```cpp
if (x = 5) { ... }   // BUG: assigns 5 to x, then checks if 5 is "truthy" (always true!)
if (x == 5) { ... }  // correct: compares x to 5
```

---

## 6. Logical Operators (Combining Conditions)

| Operator | Meaning | Example |
|---|---|---|
| `&&` | AND — both must be true | `age >= 18 && hasID` |
| `\|\|` | OR — at least one must be true | `isWeekend \|\| isHoliday` |
| `!` | NOT — flips true/false | `!isRaining` |

```cpp
int age = 20;
bool hasLicense = true;

if (age >= 18 && hasLicense) {
    std::cout << "You can drive.";
}
```

### Short-Circuit Evaluation (Important Rule)

```cpp
if (a != 0 && (10 / a) > 2) { ... }
```

With `&&`, if the **first** condition is `false`, C++ does NOT even evaluate the second — it already knows the whole thing is `false`. This is a real technique to avoid errors (like division by zero) safely.

Same logic applies to `||`: if the first is `true`, the second is skipped since the result is already `true`.

---

## 7. Truthy/Falsy Values in Conditions

In C++, any non-`bool` expression used as a condition is implicitly converted:
- `0` → `false`
- Any non-zero number → `true`
- `nullptr` → `false`
- Non-null pointer → `true`

```cpp
int x = 5;
if (x) {                // true, since x != 0
    std::cout << "x is non-zero";
}

int* ptr = nullptr;
if (ptr) {               // false, since ptr is null
    std::cout << "won't print";
}
```

---

## 8. Nested `if` Statements

You can put an `if` inside another `if` for multi-level decisions:

```cpp
int age = 25;
bool hasTicket = true;

if (age >= 18) {
    if (hasTicket) {
        std::cout << "Entry allowed.";
    } else {
        std::cout << "Buy a ticket first.";
    }
} else {
    std::cout << "Must be 18+.";
}
```

Nesting is powerful but can get hard to read — often combining conditions with `&&` is cleaner:
```cpp
if (age >= 18 && hasTicket) {
    std::cout << "Entry allowed.";
}
```

---

## 9. The Ternary Operator (Compact `if...else`)

```cpp
condition ? valueIfTrue : valueIfFalse;
```

```cpp
int age = 20;
std::string status = (age >= 18) ? "Adult" : "Minor";
std::cout << status;
```

Equivalent to:
```cpp
std::string status;
if (age >= 18) {
    status = "Adult";
} else {
    status = "Minor";
}
```

Best used for **simple, single-value** decisions — not for complex logic (readability suffers).

---

## 10. `switch` Statement (Alternative Branching for Fixed Values)

When checking ONE variable against many exact values, `switch` is often cleaner than a long `if...else if` chain:

```cpp
char grade = 'B';

switch (grade) {
    case 'A':
        std::cout << "Excellent";
        break;
    case 'B':
        std::cout << "Good";
        break;
    case 'C':
        std::cout << "Average";
        break;
    default:
        std::cout << "Invalid grade";
}
```

**Key rules:**
- `break` is required after each case — without it, execution **falls through** to the next case (runs it too).
- `default` runs if no case matches (like a final `else`).
- `switch` only works with integral types (`int`, `char`, `enum`) — NOT with `string` or `double`.

**Fall-through example (usually a bug, but sometimes intentional):**
```cpp
int day = 6;
switch (day) {
    case 6:
    case 7:
        std::cout << "Weekend";   // runs for BOTH 6 and 7, since no break after case 6
        break;
    default:
        std::cout << "Weekday";
}
```

### `if` vs `switch`

| `if...else if` | `switch` |
|---|---|
| Works with any condition (ranges, multiple variables) | Works with exact value matches on ONE variable |
| More flexible | More readable for many fixed options |
| Can use `&&`, `\|\|`, comparisons | Cannot use complex conditions |

## 11. Common Mistakes (Rules to Remember)

```cpp
// 1. Missing braces with multiple statements — only the first line is "inside" the if
if (x > 5)
    std::cout << "big";
    std::cout << "always runs!";   // NOT part of the if! Always executes.

// Correct:
if (x > 5) {
    std::cout << "big";
    std::cout << "still inside if";
}
```

```cpp
// 2. Dangling else — else binds to the nearest unmatched if
if (a > 0)
    if (b > 0)
        std::cout << "both positive";
    else
        std::cout << "this else belongs to the INNER if, not the outer one!";
```

```cpp
// 3. Using = instead of ==
if (isValid = true) { ... }   // always true — bug!
```

## 12. Solved Example — Grading System

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks;
    cout << "Enter marks: ";
    cin >> marks;

    if (marks < 0 || marks > 100) {
        cout << "Invalid marks entered.";
    }
    else if (marks >= 90) {
        cout << "Grade: A";
    }
    else if (marks >= 75) {
        cout << "Grade: B";
    }
    else if (marks >= 50) {
        cout << "Grade: C";
    }
    else {
        cout << "Grade: F";
    }

    return 0;
}
```

**Trace for `marks = 82`:**
```
82 < 0 || 82 > 100?   → false, skip
82 >= 90?               → false, skip
82 >= 75?               → true → prints "Grade: B", stops
```

## Quick Reference Summary

| Concept | Key Idea |
|---|---|
| `if` | Runs block only if condition is true |
| `else` | Runs when `if` condition is false |
| `else if` | Checks another condition if previous ones failed |
| `&&` / `\|\|` / `!` | Combine/negate conditions, with short-circuit behavior |
| Ternary `? :` | Compact if-else for single values |
| `switch` | Cleaner for matching one variable against many fixed values |
| `break` | Required in `switch` to prevent fall-through |
