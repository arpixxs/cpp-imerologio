
# Introduction to C++

## What is C++?

C++ is a general-purpose, compiled, statically-typed programming language. It was created by **Bjarne Stroustrup** in 1979 (originally called "C with Classes") as an extension of the C language, adding object-oriented programming while keeping C's performance and low-level control.

## Key Characteristics

- **Compiled language** — source code is fully translated into machine code before running (not interpreted line-by-line).
- **Statically typed** — every variable's type is known and checked at compile time, not while the program runs.
- **Middle-level language** — combines low-level features (direct memory access, pointers) with high-level features (classes, templates, STL).
- **Multi-paradigm** — supports:
  - Procedural programming (functions, step-by-step logic)
  - Object-oriented programming (classes, objects, inheritance)
  - Generic programming (templates)
- **Manual memory control** — you can allocate and free memory yourself, or use smart pointers, giving fine control over performance.
- **Platform-independent code, platform-dependent binary** — the same `.cpp` code can be compiled on different systems, but the compiled executable only runs on the OS/architecture it was built for.

## Why Learn C++?

- Used in system software (operating systems, drivers)
- Game engines (Unreal Engine, most AAA games)
- High-performance applications (finance, real-time systems)
- Embedded systems and robotics
- Foundation for understanding memory, pointers, and how computers actually work

## C vs C++ (quick note)

| C | C++ |
|---|---|
| Procedural only | Procedural + OOP |
| No classes/objects | Has classes/objects |
| No built-in string type | Has `std::string` |
| Simpler, closer to hardware | More features, more abstraction available |

## Your First C++ Program

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

- `#include <iostream>` → gives access to input/output tools.
- `int main()` → the entry point; every C++ program execution starts here.
- `std::cout` → used to print output to the screen.
- `return 0;` → tells the operating system the program ran successfully.

## How You Run It

```bash
g++ main.cpp -o main
./main
```

(This single command internally goes through preprocessing → compilation → assembly → linking — covered in the separate compiler/linker notes.)
